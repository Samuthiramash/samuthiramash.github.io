# Ashok Kumar Samuthira — Personal Website

Personal brand website for Ashok Kumar Samuthira, hosted with GitHub Pages.

## Local structure

- `index.html` — homepage
- `blog/` — published blog pages
- `CNAME` — custom domain configuration

## Domain

The site is configured for `https://www.ashoksamuthira.com/`.

## GitHub Pages

In GitHub, open **Settings → Pages** and select **Deploy from a branch**, then choose `main` and `/ (root)`.
